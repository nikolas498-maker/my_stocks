# Stock Manager 📈

Flask εφαρμογή διαχείρισης προσωπικού χαρτοφυλακίου μετοχών.

## Λειτουργίες

- 🔐 Εγγραφή / Σύνδεση χρηστών (κωδικοί με hash, όχι plaintext)
- ➕ Προσθήκη αγοράς μετοχής (ticker, μετοχές, τιμή, νόμισμα, ημερομηνία)
- ✏️ Επεξεργασία και 🗑️ διαγραφή συναλλαγών
- 📊 Dashboard με σύνοψη θέσεων ανά ticker
- 📈 Τρέχουσα τιμή μέσω Finnhub API
- 💰 Συνολική επένδυση, τρέχουσα αξία, κέρδος/ζημιά, ποσοστό απόδοσης
- 💵 Υποστήριξη πολλαπλών νομισμάτων (EUR / USD / GBP) με αυτόματη μετατροπή
- 📊 Γραφήματα (κατανομή χαρτοφυλακίου + επένδυση vs τρέχουσα αξία) με Chart.js
- 💾 SQLite βάση δεδομένων (`portfolio.db`, δημιουργείται αυτόματα)

## Εγκατάσταση

```bash
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Ρύθμιση API key (για τρέχουσες τιμές)

Οι τρέχουσες τιμές έρχονται από το [Finnhub](https://finnhub.io/register) (δωρεάν tier).
Μετά την εγγραφή, πάρε το API key σου και όρισέ το ως environment variable:

```bash
# macOS/Linux
export FINNHUB_API_KEY="το_key_σου"

# Windows PowerShell
$env:FINNHUB_API_KEY = "το_key_σου"
```

Χωρίς αυτό, η εφαρμογή δουλεύει κανονικά αλλά δεν εμφανίζει τρέχουσες τιμές/κέρδη-ζημιές
(θα δεις "N/A" και μια προειδοποίηση στο dashboard).

Επίσης καλό είναι να ορίσεις ένα δικό σου `SECRET_KEY` για τα session cookies:

```bash
export SECRET_KEY="κάτι-τυχαίο-και-μυστικό"
```

## Εκτέλεση

```bash
python app.py
```

Άνοιξε το http://127.0.0.1:5000 στον browser σου, κάνε εγγραφή και ξεκίνα να προσθέτεις αγορές.

## Σημειώσεις

- Η μετατροπή νομισμάτων γίνεται μέσω του δωρεάν API [frankfurter.app](https://frankfurter.app)
  (δεν χρειάζεται key). Όλα τα συνολικά ποσά στο dashboard εμφανίζονται σε EUR.
- Οι τιμές μετοχών γίνονται cache για 60 δευτερόλεπτα ώστε να μη χτυπάμε άσκοπα το API.
- Δοκιμασμένο με πραγματικά tickers (π.χ. AAPL, MSFT, GOOGL). Ελληνικές μετοχές ή λιγότερο
  γνωστά symbols μπορεί να μην υποστηρίζονται από το δωρεάν tier του Finnhub.
